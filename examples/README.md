# Examples

This folder holds runnable code, configurations, and diagrams that
chapters in `../book/` reference.

## Conventions

- One subfolder per topic. The subfolder name matches the topic in
  `../SUMMARY.md`.
- Each example is a small, self-contained snippet. Keep it short.
- An example must illustrate a teaching point that appears in a
  chapter. Avoid orphan examples.
- Every example folder contains a `README.md` with:
  - The chapter and section it supports.
  - How to run or read it.
  - What weaker alternative it is contrasted against.
- Do not commit secrets, real credentials, or vendor-specific
  artifacts that lock the example to a private environment.
